# GoIT JS Homework 04 - Objects & Context (`this`)
JavaScript homework assignment for the GoIT course (Module 4). Topic: working with objects, extracting object values using `Object.values()`, calculating averages, and using object methods with the `this` context.

**What was done:**
- Set up the repository `goit-js-hw-04` and configured the project structure according to the course requirements
- **Task 1 (Goods Packaging):** Implemented the `isEnoughCapacity` function to calculate the total amount of products in an object using `Object.values()` and `reduce()`, returning `true` or `false` based on container size limits
- **Task 2 (Calorie Calculation):** Implemented the `calcAverageCalories` function to compute the average daily calorie intake from an array of daily objects, safely handling empty arrays to return `0`
- **Task 3 (Player Profile):** Implemented the `profile` object containing data properties (`username`, `playTime`) and methods (`getInfo`, `changeUsername`, `updatePlayTime`) utilizing the `this` keyword to manage and display user activity
- Verified code formatting with Prettier and ensured zero errors or warnings in the browser console across all tasks via GitHub Pages
